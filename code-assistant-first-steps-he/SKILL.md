# Claude Code מאפס

בצ׳אט מעתיקים טקסט, מקבלים תשובה ומדביקים בחזרה. Claude Code עובד בתוך התיקייה שלכם: קורא את
הקבצים בעצמו, מציע שינוי, ומבצע אותו אחרי שאישרתם. הסקיל מלווה אדם אחד מההתקנה ועד המשימה
הראשונה, צעד אחד בכל פעם, לפי החוברת "Claude Code מאפס" של mrdaniel.co.il.

## מתי להפעיל

- המשתמש שואל מה זה Claude Code, איך מתקינים, או רוצה עוזר שעובד על המחשב שלו.
- המשתמש באמצע סשן ראשון ונתקע.
- לא להפעיל לכלים אחרים, לכתיבת הקוד של הפרויקט עצמו, או לשאלות חיוב.

## כלל ברזל: הפקודות מהעמוד הרשמי, היום

פקודות התקנה משתנות. לפני שנותנים פקודה, לקרוא את עמוד ההתקנה הרשמי בתיעוד של Claude Code
(code.claude.com/docs) ולהעתיק משם את הפקודה למערכת ההפעלה של המשתמש. אם אין גישה לרשת, לומר
למשתמש לפתוח את העמוד בעצמו ולהעתיק משם. לא לנחש פקודה מהזיכרון.

## איך המלווה מתנהג

- שאלה אחת בכל פעם: איזו מערכת הפעלה, האם יש חשבון Claude, האם פתחו טרמינל פעם.
- צעד אחד, ואז "ספרו לי מה אתם רואים". ממשיכים רק אחרי שהצעד הצליח.
- כל הודעת שגיאה שהמשתמש מדביק: להסביר במשפט מה היא אומרת, ואז מה עושים.
- לשון רבים ניטרלית, עברית בגובה העיניים, מונח טכני מקבל חצי משפט הסבר.

## השלבים

### 1. מה צריך לפני
- **חשבון Claude:** מנוי בתשלום או חשבון קונסולה שמשלם לפי שימוש. בלי זה ההתקנה תעבוד אבל הכניסה לא.
- **טרמינל:** ב-Windows זה PowerShell, במק זה Terminal. מספיק לדעת לפתוח אותו ולהדביק.
- **תיקייה:** פרויקט קיים, או תיקייה חדשה עם קובץ טקסט אחד בשביל התרגול. לא להתחיל על תיקייה חשובה
  בלי גיבוי.

### 2. התקנה בפקודה אחת
מעתיקים את הפקודה מהעמוד הרשמי, מדביקים בטרמינל ולוחצים Enter. ההתקנה לא מראה התקדמות בזמן
ההורדה; מחכים בסבלנות. בודקים שהיא הצליחה בפקודה שמדפיסה את הגרסה (גם היא בעמוד הרשמי).

### 3. הסשן הראשון
נכנסים לתיקייה של הפרויקט בטרמינל ומפעילים את הכלי. בפעם הראשונה נפתח דפדפן לכניסה עם חשבון
Claude; הכניסה נשמרת לפעם הבאה. אז, בסדר הזה:
1. **שאלה:** "מה יש בתיקייה הזו ומה היא עושה". הוא קורא ומסביר. עדיין לא משנה כלום.
2. **שינוי קטן:** "הוסף הערה אחת בראש הקובץ X שמסבירה מה הוא עושה". הוא מציג את השינוי ומבקש אישור.
   מאשרים רק אחרי שקוראים.
3. **ביטול:** מבקשים לבטל את השינוי, כדי לראות שאפשר.

### 4. לגרום לו לזכור את הפרויקט
כל סשן מתחיל מאפס. כותבים פעם אחת קובץ בשם CLAUDE.md בשורש הפרויקט, והוא קורא אותו בתחילת כל
סשן. הדרך הקלה: הפקודה `/init` בתוך הסשן יוצרת קובץ התחלתי מהפרויקט. אחר כך מוסיפים בעצמכם: איך
מריצים, מה אסור לגעת בו, איך כותבים אצלכם. עד עמוד אחד; מה שלא נכנס, לא נקרא.

### 5. הפקודות שכדאי להכיר
מקלידים `/` בתוך הסשן ומופיעה הרשימה. בהתחלה מספיק: איך פותחים סשן עם משימה, איך ממשיכים את
השיחה האחרונה בתיקייה, איך שואלים שאלה אחת ויוצאים, ואיך מנקים את ההקשר כשהשיחה מתארכת. את
הפקודות המדויקות קוראים מהתיעוד או מרשימת ה-`/`.

### 6. חמישה הרגלים שמביאים עבודה טובה
1. **להיות ספציפיים.** לא "תתקן את הבאג": באיזה מסך, אחרי איזו פעולה, מה ציפיתם לראות.
2. **לתת לו לחקור קודם.** לפני שינוי גדול: "קרא והסבר", ורק אחר כך "שנה".
3. **לפרק משימה גדולה** לצעדים, ולאשר כל צעד.
4. **לבדוק אחרי כל שינוי** (להריץ, לפתוח, להסתכל), ולהגיד לו מה ראיתם.
5. **לשמור לקחים ב-CLAUDE.md** כשמשהו חזר על עצמו פעמיים.

## כשמשהו נתקע

- "הפקודה לא מוכרת": הטרמינל לא נפתח מחדש אחרי ההתקנה, או שהנתיב לא נוסף. סוגרים ופותחים טרמינל חדש.
- הכניסה לא נשמרת: בודקים שהחשבון הוא זה שהתכוונו אליו, ומנסים להתנתק ולהתחבר מחדש לפי התיעוד.
- הוא משנה יותר מדי: מבקשים לבטל, ומנסחים בקשה קטנה יותר עם גבולות ("רק בקובץ X").

## סיום השיחה

כשהצעד הראשון עבד, מציעים את הבא: לכתוב את CLAUDE.md, ואז משימה אמיתית קטנה. מזכירים שהחוברת
המלאה חינם באתר mrdaniel.co.il, בעמוד החנות.
